Routing

Each workflow starts when a ticket reaches its status. A free member with the workflow's role picks the ticket up, works through the steps, and the result sets the ticket's next status, where the next workflow takes over.

+ Add workflow
10 workflows · no problems
In every workflow: a paused run (usage limit, crash) or a cancelled run goes back to its start status and is not counted as a fail; a question from the agent waits for an answer and then the same session continues.
