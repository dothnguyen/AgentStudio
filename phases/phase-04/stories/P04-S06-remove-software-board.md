# P04-S06 — Remove the software board

Status: Done (2026-10-24)
Depends on: P04-S05 (cut-over done and verified)
Architecture: [P04 design contract](../README.md#design-contract), constraints 2–5, §C, §F

## Goal
The P03 software board is deleted completely so the generic board has a clean slate. The old code is tagged in git first. This story is the first one delivered end to end with the new `agent-studio team` story commands (S05), and that delivery is the operator's verification of the cut-over (constraint 2); its last step deletes `team.py` (whose `bug`, `board`, `boards` and `ticket` commands call the software board) and the CLI-side `team.json` fallback. The engine keeps working exactly as it does today on a database with no tickets (§F).
